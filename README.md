# Tejas Ganatra & Associates – static site (design v4: Ledger + video hero)

Single-page static site. HTML + CSS + one small script (header, mobile menu, hero video).
Preview: `python3 -m http.server` then open http://localhost:8000

Hero background video: "Movement in a city at night in an aerial shot" (Mixkit #42343), used under the Mixkit
Free License (free for commercial use, no attribution required). Replace `assets/hero-720.mp4`,
`assets/hero-360.mp4` and `assets/hero-poster.jpg` with the firm's own footage whenever available.
The video is skipped for visitors with "reduce motion" or data-saver on (they see the poster image), and
there is a Pause button for everyone else.
